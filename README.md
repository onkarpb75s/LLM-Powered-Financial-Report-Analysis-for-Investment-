# LLM-Powered Financial Report Analysis

Research project: extracting structured investment-related signals from German and EU annual reports using FinBERT and LLaMA 3.

> **Important reproducibility note:** This GitHub package is a portfolio-ready project scaffold prepared from the submitted project report. The original implementation notebooks/source files and raw annual-report corpus were not included in the upload used to prepare this package. Therefore, this repository does **not** claim to contain the original executable pipeline. Replace the scaffold modules with your actual code before presenting it as a fully reproducible implementation.

## Project overview

The study describes a four-module NLP pipeline for annual reports covering 2015–2024. It processes report sections — Management Discussion and Analysis (MDA), Risk Factors, Outlook, and Financial Highlights — and combines financial sentiment and LLM-derived signals with market/fundamental features.

### Reported study scope and results

- 491 source documents across 40+ companies, including DAX 40 and SEC EDGAR 20-F filings.
- 398 labelled documents remained after year, label, and return-data filters.
- Labels: 229 outperform (57.5%) and 169 underperform/neutral (42.5%).
- FinBERT generates sentence-level sentiment features.
- LLaMA 3 (8B), run through Ollama, extracts structured scores such as sentiment, risk intensity, forward-looking tone, and management confidence.
- Reported model macro-F1: Logistic Regression 0.748, XGBoost 0.822, LightGBM 0.753, LSTM 0.677.

These figures are transcribed from the accompanying academic report; they are not results generated by the starter code in this repository.

## Setup

```bash
git clone https://github.com/YOUR-USERNAME/financial-report-analysis.git
cd financial-report-analysis
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```

The current modules are interfaces/scaffolding. Complete them using your original notebook/source code and configure the model assets before running an end-to-end experiment.

## Responsible use and limitations

This is an academic research prototype, not investment advice or a trading system. Report-derived performance metrics should not be interpreted as evidence of future returns. Reproduction requires the original data, preprocessing decisions, model versions, prompts, random seeds, and evaluation split details. Do not commit licensed annual reports, API keys, private data, or large model weights.
